# 01MVP Update

Generate reader-facing 01MVP update materials from recent docs/product changes.

## Install

```bash
npx skills add makerjackie/skills --skill 01mvp-update
```

## Usage

```txt
/01mvp-update
/01mvp-update 总结最近一周更新，重点强调手册路径重构和 Blueprint 风格
```

The skill updates the website changelog directly, refreshes recent-update
surfaces when available, and creates one archive Markdown file plus a WeChat
official-account HTML file.

## Default Output

```txt
output/01mvp-updates/YYYY-MM-DD-<slug>.md
output/01mvp-updates/YYYY-MM-DD-<slug>.wechat.html
```

The Markdown file contains:

- website updates applied
- WeChat official-account article
- WeChat group message
- X/Twitter copy
- Xiaohongshu text copy
- English update
- source evidence

Xiaohongshu images are not generated by default.
