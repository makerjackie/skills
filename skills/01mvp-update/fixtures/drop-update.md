标题：01MVP.com 更新：一键拖拽，把 HTML 变成网址

正文：
今天网站新增了一个很实用的小功能：01MVP Drop。

我们现在经常 vibe coding 去写 HTML，比如类似 PPT 的 slide、产品宣传页、作品集、小工具页面等等。

但写完以后，最麻烦的地方往往不是页面本身，而是分享。

你想发给朋友看，通常需要部署、配置静态站点、处理文件路径，甚至还要折腾域名。对于一个只是想快速分享的 HTML 来说，这个流程太重了。

## 现在可以怎么用

现在你只需要打开 01MVP Drop，把你的 HTML 页面或者 zip 压缩包上传上去，它就会直接变成一个网址。

朋友点开链接就能访问，不需要你再单独部署。

地址：https://01mvp.com/drop
