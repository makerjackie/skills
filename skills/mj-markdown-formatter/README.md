# mj-markdown-formatter

Markdown 文章排版和基础校对 skill。它用于整理已经成型的文本，修复 Markdown 语法、中文空格、标点、错别字和基础 front matter。

## 安装

```bash
npx skills add makerjackie/skills --skill mj-markdown-formatter
```

## 快速使用

```text
Use $mj-markdown-formatter to format this Markdown article without changing the core wording.
```

```text
Use $mj-markdown-formatter to fix punctuation, Chinese-English spacing, headings, and code fences in this draft.
```

## 适用边界

- 适合处理排版、格式、标点、空格和明显错别字。
- 不负责重写文章结构。
- 不负责把素材写成文章。需要创作时使用 `mj-writer`。
- 不负责公众号、小红书等平台发布适配。需要分发素材时使用 `mj-adapt`。

---

## 为什么需要这个 skill？

很多文章已经写完了，但 Markdown 标题、代码块、空格和标点会影响阅读质感。`mj-markdown-formatter` 只做最后的格式收口，尽量不改变原文的判断和语气。
