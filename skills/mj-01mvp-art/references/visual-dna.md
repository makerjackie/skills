# Visual DNA

## Source

This skill is adapted from the open-source `helloianneo/ian-xiaohei-illustrations` skill, which is MIT licensed. Reuse the method: find a cognitive anchor, then draw a low-tech physical metaphor.

Do not reuse Ian's Xiaohei IP, bean-shaped character, thin-line style, or old example compositions. 01MVP uses its own chunky `01` operator style.

## Style Anchor

Use `assets/examples/00-character-exploration.png` as the only built-in calibration image.

Core traits:

- Chunky black rectangular `01` operator.
- Thick black marker outline and solid black fills.
- Short sturdy arms and legs.
- White background.
- One red-orange accent.
- Large, simple physical action.
- Very few objects.
- Clear at thumbnail size.

## Composition

Prefer these simple patterns:

- Big messy thing -> hard action -> small clean result.
- Manual crank -> payment/feedback signal -> automation later.
- Feature pile -> cut scope -> launch flag.
- Question mark -> validation action -> open door.
- Checklist pile -> operator marks only the blockers.

Avoid:

- PPT flowcharts.
- Many arrows.
- Thin-line diagrams.
- Cute mascots or pets.
- Decorative scenes.
- Long paragraphs inside the image.
